栖屏电视桌面｜四轮视觉与功能改造规范
基线：用户提供的 0.2.9 完整源码。此包是设计交接，不含修改后的工程。

一、依据与优先级
1. 用户最新明确要求 > 本规范中对样图的纠正 > 0.2.9 已有业务/数据/兼容行为 > 八张概念样图的装饰细节。
2. 现有首页顺序固定：影视、直播、音乐、相册、全部应用。前四项绑定外部 App，第五项打开应用库。设置、网络入口仍在右上角。用户实机照片已核实：时间右侧有 Wi-Fi 与齿轮。这里指齿轮入口位置，不是面板位置；齿轮可打开样图右侧磨砂面板。禁止把样图的六图标 Dock 当成新增第六入口或改序的授权。
3. 保留五张横向约 16:9 卡片的已确认比例、统一缩放及超宽屏适配；不要照抄概念图近方形卡片。底栏无文字，功能标题放在主屏。
4. 相册/音乐/影视/直播仍是快捷入口，不新增照片扫描、媒体库、播放器、内容源。背景与音乐封面是主题素材，不表示播放内容。
5. 八张图是逐轮代表页面，不是完整组件状态图，也不是运行截图。正式实现不能把图中装饰性箭头、双焦点、云图标等误差照搬。

布局坐标核对：现有 StageLayout 使用 960×540 逻辑坐标，并非设备 px/dp。1080p 参考值应统一换算为逻辑坐标，再由现有布局缩放，不能重复缩放。

二、确认的视觉方向
以先前第三张快捷设置图的石墨深色磨砂材质为母风格：深色半透明容器、银白图标、克制的细边缘高光、清楚但不过曝的焦点。保留风景背景的可见性，信息区域可叠局部暗渐变帮助阅读。不是全屏白卡、霓虹描边或厚重立体按钮。
继续使用现有五类背景，随选中入口变化；不要把这次八张统一暮色示例理解为所有入口只能一张壁纸。
正式标识从工程 design/icons 和既有资源复用，不采用生成图中近似 Q 字。

以下是建议起始值，不是从样图反推的精确量测；必须结合 StageLayout 的既有缩放体系校准，不另建第二套全局缩放：
- 默认保持用户已选边距 3%/5%/7%；新用户可沿用当前默认。所有文本、焦点外扩和浮层都在安全区内，不能把图05/06/08贴到最右边缘。
- 面板底色可从 #171C25 约 90% 不透明度起调；边线白色约 12% 不透明度；普通正文近 #F2F3F5，次文字近 #B8BDC6。
- 焦点细边：以 1080p 设计画布约 2px 为起点，轻量模式可保持清晰边线而取消光晕；焦点亮度不能掩盖文字。
- 焦点放大建议约 1.04，第一轮优先沿用现有比例和缩放机制；外扩不能裁切、遮住相邻对象或导致布局抖动。
- 焦点过渡建议 120–160ms；背景过渡沿用既有短淡入淡出/轻量策略。均为设计建议，不承诺任何设备帧率。
- 不以实时模糊作为必需条件。先复用 GlassPanel/GlassDock 等低成本绘制；需要背景柔化时用受控缓存，禁止每帧全屏截图或模糊。
- 字号统一沿用当前显示字号设置。图06的三档是后续候选扩展，不允许第一轮直接改变原存储值或忽略旧选择。
- 全应用网格展示真实 App 图标与名称，不要把所有第三方图标替换为示例里的统一银白符号。

三、第一轮：精修已有体验（图01、02）
范围：主页、Dock、现有应用卡片、现有设置及弹窗的共享材质与焦点统一。保留原有页面和功能入口，重用已有自绘组件。
已有能力：无文字 Dock、随焦点切背景、焦点放大/柔光、边缘翻页、对话框方向导航、恢复焦点、轻量模式。不得把这些列为“新实现”或创建并行版本。
重点修整：标题/次文层级，比例与留白，统一图标线条/亮度，浮层安全区，清晰的当前焦点。
第一轮不新增最近打开、第二套收藏、长辈模式、配置备份；不扩展在线更新或壁纸。
沿用 reduce_motion 的现有作用范围：虽然设置名称是“背景动效”，当前实际同时影响背景渐变、Dock、应用卡片与设置卡片的焦点动画。不得缩窄成只控制背景，也不要新增语义冲突的开关。第一轮保留原文案；后续改名应如实说明作用范围。

四、第二轮：常用应用整理（图03、04）
真正新增：从栖屏成功发起的应用打开记录，以及独立收藏管理页。若源码后续已有同等能力，复用而非重复实现。
最近打开：仅记录本桌面发起且未抛出错误的启动请求，不声称外部 App 已实际播放；去重、有限条数（建议12）、最近优先；支持关闭记录与清空；关闭后不继续采集。只存本机包/组件标识及必要时间，不采集跨应用观看历史。
收藏：与四个固定首页分类绑定、旧版六常用槽分离。建议新列表上限12，独立持久化；不自动把旧槽迁移或覆盖。支持添加、左移/右移、移出收藏；移出不卸载。旧数据与旧入口可继续访问。
建议入口放在全部应用页的可聚焦工具区：“最近打开”“收藏”；不得删除刷新、更新等已有入口，拥挤时改为单一管理菜单。不把新功能塞成第六/第七个首页 Dock。
图04的卡片选中态表示操作对象；真正活动焦点仅在菜单当前行。不可出现两个同强度的遥控器焦点。
空列表、App卸载、打不开、列表读取失败都需可返回的文字状态，不能遗留不可选中的幽灵卡片。修改收藏后重启仍保留。

五、第三轮：快捷设置（图05、06）
新增或重组快捷设置侧栏，但保留完整设置页及全部九项能力。原右上角设置进入快捷侧栏，侧栏必须有“全部设置”，不能让开机与桌面、网络、其他桌面、第一版常用、启动状态、关于等消失。
图05“外观主题”若无完整主题实现，替换为已有“背景动效”，不做无效占位按钮；不得擅自引入在线主题市场。
侧栏优先映射现有字号、边距、背景动效、设备与性能和系统设置能力，读写同一份设置，退出/再进显示一致。
图06若采用三档字号：先核对旧存储格式，保持旧用户视觉映射，新值可显式迁移，不清空其他偏好；只调应用内 UI，不能更改系统字号。实际值变化后再更新预览和选中勾。
焦点：打开面板保存调用者；方向键局限于面板，关闭返回原焦点。子页返回恢复父行。长按松手不误触首项。不能抢 Home/音量等系统键。
系统设置页仍由固件提供，不承诺改造成同款玻璃界面。

六、第四轮：可选家庭功能（图07、08）
07 长辈布局：是可切换首页布局，保留原五入口配置，不覆盖绑定。看电视复用直播绑定、看照片复用相册绑定、常用应用进入应用库/收藏。默认不强制启用。布局锁定只限制移动/编辑，不是安全隔离或儿童管控；必须有遥控器可达的退出/解锁设置入口。
08 本地配置备份恢复：导出有版本号、白名单字段的配置文件；涵盖分类绑定、收藏顺序、外观/字号/边距等经确认配置，不含外部 App 数据、媒体、签名密钥、系统默认桌面权限。
绝对不备份/恢复 StartupState 的本次开机令牌、执行标记、诊断时间和临时倒计时。恢复不能触发自启动，不修改本次启动已处理状态；开机自动打开开关默认维持本机状态，不能随配置静默开启。
先解析校验、预览恢复内容，再明确确认；无效/损坏/新版本不支持的文件不得部分覆盖。取消不改数据；恢复前保存可回退配置。缺失 App 标为未安装，不能崩溃。
图08云形图标必须换成本地文件导入/导出图标；说明条不应有可点击箭头。API14–18与19+文件选择差异需在实现时核实，不可为备份功能悄悄抬高minSdk。
可选本地屏保不属于这八张本次交接的实施范围，待后续单独确认，不自动扩展。

七、必须保留的底线
包名 cn.wengmang.qiping；minSdk14；原生 Java + 系统 Views；不换 Compose/Flutter/WebView，不提高最低系统要求。
保留四分类独立绑定、同 App 可绑定多个分类、卸载后重新选择、直播绑定与开机目标联动、旧版常用数据。
保留应用库两行六列与边缘翻页：不恢复页码按钮；末页不选空格；手机滑动仍可用。按原逻辑恢复页面/页码/焦点。
保留自动/轻量性能策略、受限后台解码、缓存上限、丢弃过期请求、不可见时释放引用/暂停动画，不新增常驻网络轮询。
保留现有更新入口但明确“尚未接入更新服务”；不伪造角标/可用更新，不擅自接入市场、下载器或自动安装。
保留正确签名的升级路径。不要索取用户私钥/密码；不要以卸载重装作为常规升级方案。

八、0.2.9 自启动专项不可回退
必须以源码核对中的 StartupFlow、StartupState、MainActivity 相关方法为依据。
短暂焦点丢失、onPause、重复HOME只是暂停/重置倒计时，不能提前取消整次开机机会。
真实按键/触摸可以取消本次；等待默认桌面、目录和前台焦点就绪；连续3秒倒计时后请求打开；请求前同步记录已处理；每次系统重启最多请求一次，返回桌面不循环启动。
扫描重试和整体截止时间继续有界；进程重建不能延长窗口。启动诊断页必须保留。
是否自动播放具体频道由直播App决定；桌面只负责请求打开。真正系统重启与待机唤醒不能混淆。
当前0.2.9源码包含修复，但用户尚待验证修复结果；不能在交付说明写成“电视自启动已通过”。

九、验收与交付
每轮先留回退副本，输出改动文件清单和偏好兼容说明。运行可用的既有测试，并为新增行为补最小测试。记录编译/单元逻辑/模拟器/电视验证四种结果，未执行写未执行。
重点人工检查：五入口和绑定；应用网格边缘/末页；弹窗焦点/返回/长按；字号边距组合；轻量策略；开机与返回的启动状态不回退。不要制作全量截图或录屏；只有出现具体视觉缺陷时用针对性截图说明。
交付完整源码 ZIP，不含APK、私钥、密码、SDK、构建缓存、无关本机路径。每轮完成后用户自行 Android Studio 测试，明确确认后推进下一轮。
