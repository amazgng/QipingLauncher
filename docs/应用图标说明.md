# 石墨银白安装图标（设计沿用 0.2.6，当前最低 Android 9）

本次修改的是安装后在系统桌面、应用信息、系统应用列表中显示的栖屏应用图标，以及电视系统的入口横幅。

## 确认设计

- 采用配色比较图中 A「石墨银白」。Q 的外圈形成电视边框，尾笔形成右侧支脚。
- 背景为石墨色 `#202328`；标志使用 `#ECEEF1`，尾笔与支脚只有轻微银灰差别。
- 无外围描边、外发光、套框、白色画布或装饰文字。
- 正式资源用规则矢量轮廓整理；未采用透明样图中带杂点的抠图结果。

## 安卓资源

| 用途 | 资源 |
| --- | --- |
| 传统图标资源（供系统回退读取） | `res/mipmap-mdpi` 至 `mipmap-xxxhdpi/ic_launcher.png`，80 / 120 / 160 / 240 / 320 px |
| 自适应图标（Android 9+） | `res/mipmap-anydpi-v26/ic_launcher.xml` |
| Android 13+ 主题图标 | `res/mipmap-anydpi-v33/ic_launcher.xml` 的 monochrome 层 |
| 矢量前景 | `res/drawable-anydpi-v26/ic_launcher_foreground.xml` |
| 满铺底色 | `res/values/icon_colors.xml` |
| 电视入口横幅 | `res/drawable-mdpi` 至 `drawable-xxxhdpi/tv_banner.png`，160×90 至 640×360 px |

以上 `res` 指 `app/src/main/res`。Manifest 的图标引用更新为 `@mipmap/ic_launcher`。旧版的单一 drawable 图标与旧横幅已移除。

传统 PNG 只有图标自身的圆角轮廓，外侧为透明像素，抗锯齿边缘使用石墨色。自适应图标背景满铺、不预先画圆角、不嵌套另一张圆角底板，外形交由系统裁切。前景使用 108 dp 画布，按同一几何母版缩放，所有可见内容限制在中央直径 66 dp 的圆形安全区内。

Android TV 不使用手机的主题图标能力；手机若主动启用系统主题图标，系统可能按壁纸重新着色。不同厂商桌面的最终外形、统一缩放和附加效果由系统决定；资源本身不含白边或外框。

## 母版与预览

- `design/icons/geometry.json`：统一几何和配色来源。
- `design/icons/icon_master.svg`、`mark_master.svg`：可编辑矢量母版。
- `design/icons/icon_preview.png`：正式图标预览，透明圆角外侧。
- `design/icons/mask_circle.png`、`mask_square.png`、`mask_rounded.png`：按系统可见区域生成的静态裁切检查，**不是实机或模拟器截图**。
- `design/icons/tv_banner_preview.png`：电视入口横幅预览。

全部构建所需资源已放入 `app/src/main/res`，Android Studio 无需重新导出素材。

如未来修改母版，选用安装了 Node.js、sharp 与 ImageMagick 的设计环境，设置 `QIPING_BANNER_FONT` 为支持中文的字体文件路径，然后运行 `node tools/generate_icons.js`。这是可选的设计时工具，应用运行与 Android Studio 编译不依赖它。横幅导出采用 Noto Sans CJK SC Regular，字体文件本身不随包分发。

## 本地检查

在 Android Studio 打开本版完整工程并 Run，回到系统桌面查看栖屏图标；在电视模拟器的系统应用入口查看横幅。相同签名可覆盖升级；包名未变，覆盖升级无需清除已有绑定和设置。

若系统桌面仍显示缓存的旧图标，先重启模拟器或刷新系统桌面；不必先卸载栖屏。实际海信电视的图标形状仍待实机查看。

参考：[Android 自适应图标规范](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive)、[Android TV 应用图标规范](https://developer.android.com/design/ui/tv/guides/system/tv-app-icon-guidelines)。
