栖屏 0.2.13｜第四轮交付后的完整验收清单
对象：Android Studio 模拟器 + 目标 Android 电视（个人设备标识已移除）

这份清单是需要你验证的项目，不表示已在你的电脑或电视通过。
我已执行的编译、主机逻辑和 API 19 模拟器结果，另见「验证记录.txt」。
建议先做 A–F，再做电视专项 G；异常和兼容补充项 H 仅在独立测试环境做。

A. 打开工程、升级与原数据
[ ] 将新 ZIP 解压到独立目录，用 Android Studio 打开 qiping-launcher-v0.2.13 工程根目录。
[ ] JDK / SDK 同步、构建、Run 正常；在设备信息中看到栖屏 0.2.13。
[ ] API 28 横屏 1280×720 模拟器运行，方向键、Enter 和返回键可操作，不依赖鼠标。
[ ] 电视覆盖升级时使用原签名，不卸载旧版；保留旧源码。升级后四类绑定、旧六槽常用、独立收藏、最近记录、字号/边距/性能与开机开关还在。
[ ] 新版首次运行不擅自开启长辈布局、布局锁定或开机直播，不自行打开文件导入页面。

B. 标准首页、应用库与遥控器（前三轮回归）
[ ] 标准首页仍为影视、直播、音乐、相册、全部应用五项；底栏没有文字，卡片为横向比例，正式 APK 图标保持石墨银白 Q/电视标志。
[ ] 左右焦点、主屏功能标题、背景同步；快速来回切换最终背景正确，没有明显拉伸、白块或残影。
[ ] 四类应用能分别绑定、打开、更换、取消绑定；同一应用可绑定多个分类。
[ ] 未绑定入口可选择应用；已卸载/停用的绑定有提示，可重新选择，不崩溃。
[ ] 上键进入右上角齿轮、下键回选中项；标准首页下键/最右侧继续按右可进入全部应用，返回恢复原焦点。
[ ] 全部应用保持两行六列和真实 App 图标/名称。数量超过 12 时左右边缘直接翻页、保持所在行；最后一页没有空格焦点，不需要点击页码。
[ ] 打开应用再返回，应用库页数和焦点合理恢复；刷新后应用增删能反映。手机横屏下原有滑动翻页仍可用。
[ ] 菜单键/长按确定能进入管理；松手不会误按菜单首项。弹窗的上下左右、确定、返回均可用，关闭恢复调用者焦点。
[ ] Home、音量键仍由系统处理；连续按键/长按方向键不会卡死或跳到无法返回的页面。
[ ] 最近打开只记录栖屏发起的打开请求，去重且最多 12 项；关闭记录后不再增加，清空需确认。
[ ] 独立收藏可添加、左右调整顺序、移出，最多 12 项；退出/重开保留，不改四分类绑定和第一版常用。
[ ] 空收藏/空最近记录可返回；卸载测试 App 后有缺失提示，清理不可用收藏需确认，不误删其他记录。

C. 快捷设置、显示与性能
[ ] 齿轮打开右侧石墨面板；原六项可达，左右不穿透到背景，返回回齿轮。
[ ] 标准/大号/特大：方向键只选焦点，确定才改值；返回再进勾选正确，旧大字保持对应大号。
[ ] 3%/5%/7% 边距与三档字号的九种组合下，标题、应用名称、侧栏、新三卡首页、备份预览可读，无明显裁切、挤压或超出电视边缘。
[ ] 侧栏/完整设置共用字号、边距、动效；关闭动效同时简化背景和焦点过渡。
[ ] 全部设置原九项、应用更新、启动状态和使用说明都能进入；设备/开机子页逐级返回，系统设置返回仍落在原入口。
[ ] 设备型号、Android 9/API 28、分辨率、内存/空间信息合理；手动轻量模式保存，切回自动仍可用。
[ ] 轻量模式下反复切换背景、应用库和设置、打开外部应用再返回，无闪退/持续卡顿；待机返回正常。电脑效果不能代替低内存电视实测。
[ ] 更新入口明确没有接入服务，不出现假更新角标；这一轮不验收 APK 自动下载/安装，也没有联网壁纸或屏保。

D. 新增长辈布局与布局锁定
入口：齿轮 → 全部设置 → 底部「家庭与配置」。
[ ] 开启长辈布局后只有「看电视」「看照片」「常用应用」三张大卡；上键可到设置，下键可到「布局与解锁」。
[ ] 看电视打开原直播绑定；看照片打开原相册绑定；常用应用进入原应用库，并能进入收藏/最近打开。
[ ] 三卡左右移动有唯一清楚焦点，背景跟随；从外部应用或应用库返回，回到刚才的卡片。
[ ] 直播/相册未绑定时，未锁定状态可选 App，取消不写入；不要为测试卸载日常直播 App，可在模拟器用测试 App。
[ ] 开启布局锁定后仍可打开应用、进设置；修改分类、更换开机直播目标、收藏添加/移动/移出受阻，并提示解锁路径。
[ ] 锁定后「布局与解锁」仍可达；关闭锁定后编辑恢复；关闭长辈布局立即回原五入口，原四分类绑定仍在。
[ ] 关闭/重开栖屏后长辈布局与锁定状态保持；锁定只防误编辑，没有把它当密码或儿童保护使用。

E. 本地备份、恢复、撤销（先在模拟器完成一遍）
入口：「家庭与配置 → 桌面配置」。
推荐先设一组容易辨认的 A 配置，例如特大字、7% 边距、两项收藏；备份 A 后改为 B，再恢复 A，最后撤销回 B。
[ ] 「备份配置」显示已保存；应用内备份列表有新副本，反复手动备份最多保留最近 5 份。
[ ] 「另存为文件」能打开系统文件选择器，取消可回到备份行，应用内副本仍在。
[ ] 真正选位置保存 .qiping 文件，可在文件管理器看到；复制到电脑/U 盘留存。没有保存器时显示应用专属目录路径。
[ ] 「恢复配置 → 应用内备份」能选文件、先显示预览；「选择备份文件」可读取刚导出的实际文件。
[ ] 系统文件选择器若先显示位置侧栏/文件夹，按返回逐层退回；最终回栖屏「恢复配置」，焦点正确，不误执行恢复。
[ ] 预览四绑定、收藏顺序、字号/边距/动效/性能/长辈/锁定状态正确；长说明可上下滚动，左右能到确认/取消。
[ ] 预览中返回或取消，不改变 B 配置；仅选择文件也不改变任何设置。
[ ] 确认恢复后匹配 A 配置，包括收藏顺序；返回首页和各设置页显示一致，关闭/重开后还在。
[ ] 缺失测试 App 时预览标「未安装」；恢复只保留标识，不自动安装、崩溃或把其他绑定删掉。
[ ] 「撤销上次恢复」先预览，再确认回 B；原值/顺序恢复。重新启动栖屏后也能撤销；成功撤销后该撤销点被消耗。
[ ] 再恢复一份配置后，撤销对应这一次恢复前的状态；手动备份仍保留。
[ ] 备份若带锁定，恢复后先通过「家庭与配置」解锁，再撤销；不能把用户困在锁定布局。
[ ] 恢复前后，最近打开及记录开关、第一版常用、开机直播开关保持本机状态；恢复不授予默认桌面、不立即拉起直播。
[ ] 保留到应用之外的文件能从电脑/U 盘重新导入；仅在应用内的副本不要当作卸载后的保障。

F. 重启栖屏与日常往返
[ ] 退出/重新打开后：首页模式、锁、绑定、收藏顺序、字号/边距/动效/性能值均保持。
[ ] 打开直播/相册/系统设置/文件选择器再返回，页面、焦点、背景正常，没有悬空弹窗或死路。
[ ] 手机横屏作为辅助测试可触控，但电视的方向键验收单独做；不以手机画面比例作为电视效果结论。

G. 海信电视必须实测的开机直播（此前修复仍未验收）
准备：确认栖屏为默认桌面，直播绑定有效，先在「开机与桌面 → 立即试播」确认能打开 App。
[ ] 开启自动打开后，当次不要立即拉起；先拍下「启动状态」的启动标识/运行时间作对照。
[ ] 做真正系统重启（系统重启功能或正常关机后的重新上电），不是只按遥控器关屏。进入栖屏后先不碰遥控器，观察稳定前台后的 3 秒倒计时与打开请求。
[ ] 若没打开，进入「启动状态」记录原因、是否默认桌面、当前/已处理启动标识和运行时间；这能区分待机、绑定、扫描或固件问题。
[ ] 打开直播后按返回/Home 回栖屏，不再循环拉起；重复进入桌面也不重试本次已处理启动。
[ ] 另一次真正重启，在倒计时按返回或任意方向键，取消本次自动打开；随后停留桌面不重新拉起。
[ ] 待机唤醒不误算新重启、不反复拉起。关闭开关后再真正重启不自动打开。
[ ] 标准首页和长辈布局各验证一次；长辈布局倒计时应落到「看电视」卡片，取消和返回语义一致。
[ ] 恢复配置不会立即拉起；若本机开关原已开，下次重启使用恢复后的直播绑定。若原关闭，恢复后仍关闭。
[ ] 记录“App 已打开”和“频道开始播放”两件事：栖屏负责请求打开，直播 App 是否自动播放由它自身决定。

H. 异常与旧系统补充（独立模拟器/测试文件，不破坏日常配置）
[ ] 复制备份后截断或改内容，导入显示失败且当前配置不变；超 32 KiB、未知格式/版本文件同样不部分覆盖。
[ ] 选择不可读文件、取消系统授权/选择、U 盘拔出或导出失败有提示，能返回；应用内已保存的副本不被误删。
[ ] 仅在可丢弃的测试环境模拟空间不足/恢复中进程被终止，重开后检查原值恢复提示和可用的重试路径；不要为此填满电视存储或清除日常数据。
[ ] 如将来要支持 Android 4.0–4.3 实机，再验证 GET_CONTENT 文件导入、旧系统专属目录导出及无文件管理器回退。本次 API 14 编译不等于旧系统文件管理器实测。
