# 0.2.15 个性化设计

延用 0.2.14 的六套内置风景与石墨银白透色玻璃，自有图标继续从当前背景取色。内置图像来源与历史设计说明见 `history/0.2.14_设计与资源.md`。

新增个性化菜单沿用现有 GlassDialog；快捷设置增加个性化行，完整设置顶部增加同名入口。全部应用底部保留固定整理入口，隐藏全部内容后仍可恢复。首页按显示数量均分可用宽度，图形自身仍保持原比例；全部应用入口不能隐藏，允许移动。

空闲屏保在 Activity 内复用 SceneView 的背景；不注册后台覆盖层、不申请悬浮窗权限，也不强制改变系统休眠策略。时钟每分钟重绘并轻微改变位置。启动浮层不获取焦点，退出时焦点回到原控件。

本地壁纸使用系统选图意图，文件复制和解码在单独线程，API 28 ImageDecoder 限定输出尺寸和软件分配。处理照片方向，统一转为 JPEG，成功写入后原子替换，刷新场景和玻璃缓存。默认壁纸始终保留在资源中。

配置备份新增 v2；新的排列/隐藏与屏保字段纳入预览、提交、撤销和恢复日志，兼容旧 v1。图片保留本机，不在备份文本中传输。

运行截图 `design/runtime/` 来自 API 28 横屏测试。应用排序和隐藏画面中的“应用 N”是测试夹具；自定义壁纸是测试中生成的渐变图片，用于核对导入和透色，并非新增内置主题。开机直播实测状态不由这些截图证明。

平台接口依据：
- https://developer.android.com/guide/components/intents-common （ACTION_OPEN_DOCUMENT / ACTION_GET_CONTENT）
- https://developer.android.com/reference/android/graphics/ImageDecoder （API 28 解码、尺寸和软件分配）
