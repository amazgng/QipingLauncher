栖屏 0.2.19 · Android Studio 源码使用与验收

一、安装与版本
支持 Android 9 及以上，versionCode 21。用 Android Studio 打开完整工程，沿用原包名和你自己的签名覆盖安装。保留 0.2.18 源码供对比。不要先卸载旧版，以免丢失壁纸和配置。

二、设置入口
首页齿轮 → 全部设置。
第一排：开机与桌面 / 家庭与配置 / 网络设置。
第二排：系统设置 / 其他桌面 / 设备与性能。
第三排：应用更新 / 个性设置 / 使用说明。

“个性设置”位于原“第一版常用”位置。界面动效、屏幕边距、显示字号、首页排列与隐藏、全部应用整理、桌面空闲屏保、本地壁纸均在里面；手机传壁纸继续位于本地壁纸中。
原“个性化”顶部与快捷面板入口、底部“家庭与配置”按钮及“第一版常用”入口已删除。原绑定、排列、收藏、壁纸与显示偏好保留。

三、设置未成年模式
1. 全部设置 → 家庭与配置 → 未成年模式。
2. 设定 6 位家长密码，输入两次。
3. 用纸笔或手机保存屏幕上的 12 位恢复码，再输入恢复码确认保存。恢复码不可交给孩子。
4. 进入“允许的应用”，确定键切换勾选；可选多个。至少选择一个后才能开启。
5. 如需时段限制，进入“允许打开的时段”，设置开始与结束时间（输入 HHMM，例如 1930），再开启“时段限制”。默认不限时段。开始时间包含，结束时间不包含；支持 22:00—06:00 这种跨午夜时段。
6. 返回家长设置，开启未成年模式。桌面只显示选定的已安装应用。
7. 退出：儿童首页 → 家长管理 → 输入密码 → 未成年模式：已开启 → 退出模式。

密码键盘用上下左右选择数字、确定键输入；“删除”删最后一位，“确定”提交，“取消”返回。也可使用遥控器数字键。连续输错 5 次后需等待 30 秒；密码和恢复码共用错误次数。恢复码可从验证页“忘记密码”入口使用，重新设置后旧密码和旧恢复码失效。

四、限制范围
这是栖屏内的应用入口管理。超出时段后显示休息页面并禁止新的打开请求，不能强制停止外部应用已经播放的视频。允许一个视频应用也不等于过滤该应用内的所有内容，请配合其儿童模式。
系统按键、语音助手、其他桌面和应用内跳转等可能绕过；修改系统时间会影响时段判断。卸载或清除栖屏数据也会清除规则。没有接入设备所有者、无障碍服务或整机家长控制。

家长规则和密码独立保存，不进入普通桌面配置备份，不被恢复配置或撤销恢复覆盖。覆盖安装和正常重启会保留模式；系统级数据损坏不在此保证范围内。忘记密码且丢失恢复码时没有万能密码，请妥善保管恢复码。

五、建议在电视上验证
A. 设置归并：用方向键进入全部设置，检查九张大卡片；从原常用位置进入个性设置，动效、边距、字号均可改；从子项返回能回到正确位置。
B. 原功能：原绑定、收藏、排序、壁纸仍在；长辈布局和配置备份入口正常。
C. 密码：先取消一次密码设置，确认未开启；完整设置并记下恢复码；输错密码不应进入家长管理，正确密码应能进入。
D. 允许列表：只允许一两个测试应用，开启模式后只显示这些；按返回、菜单和长按确定不应直接打开普通设置或管理应用。
E. 时段：把允许时段设到当前时间之外，确认出现休息页面；再由家长改回当前时段，确认应用可打开。外部视频不会被强制中断，这是本版设计范围。
F. 持续状态：待机再唤醒、系统真正重启后，未成年模式仍保留；退出后恢复原首页，规则仍保存。
G. 开机直播：未成年模式关闭时按 0.2.18 流程验收；开启时，被排除或超时的直播不应自动打开。允许的直播且在时段内仍可按原流程自动打开，前提是电视发出可识别的开机 / 唤醒信号。
H. 密码恢复：使用已保存恢复码重新设置，确认旧密码失效；重新保存新的恢复码。

六、构建与专项测试
JDK 17/21；Platform 35；Build Tools 35.0.0；AGP 8.7.3 / Gradle 8.9。工程最低 API 28。
独立 SDK 构建：python3 build_local.py --sdk <SDK目录> --check-api28 --instrumentation
该命令仅在本机生成测试 APK 与测试签名，不用于覆盖你的正式签名安装。

仅限可清空数据的独立模拟器：
adb shell am instrument -w -e suite settings-family cn.wengmang.qiping.tests/cn.wengmang.qiping.tests.LauncherSmoke
专项会清理测试家长规则与密码，请勿在日常使用的电视运行自动交互测试。
