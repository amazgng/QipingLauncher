栖屏 0.2.16 · 手机传壁纸

一、在电视上使用

1. 电视安装本版后，打开：首页右上角齿轮 → 个性化 → 本地壁纸。
2. 选“手机传壁纸”；也可以先选“影视 / 直播 / 音乐 / 相册 / 全部应用 / 设置页面”，再选“手机传壁纸”。
3. 手机与电视连接同一路由器。电视接网线也可以，手机连接该路由器的普通 Wi-Fi。
4. 手机扫码打开上传页面。不需要安装配套 App，也不需要账户。
5. 扫码后无法打开：在手机浏览器中输入电视显示的完整 http://地址:端口/，再填写电视上的 6 位配对码。注意输入 http，不是 https。
6. 在手机网页选择目标界面和图片，检查预览，点击“上传到电视”。单张最多 20 MB，建议横向 JPG / PNG / WebP。
7. 电视显示收到的图片和目标分类。按左右键选择“应用壁纸”或“放弃图片”，按确定执行。
8. 继续传其他图片也可以。完成后在电视按返回，或选择“结束传输”。

连接最多有效 10 分钟。到期后选择“重新连接”，重新扫码或输入新配对码。
退出传输页面、按 Home 返回桌面、切换到其他应用、系统暂停桌面时关闭接收。
断开网络或网络地址改变时会停止接收并提示重连（正常轮询约 5 秒内检测）。
原壁纸保留到电视确认且保存成功为止。仅上传完成不会自动覆盖；退出时尚未确认的图片会清理。
上传成功并确认后，图片保存在桌面私有目录，之后不需要手机在线。
照片会处理方向并缩小到最长边最多 1920 像素；半透明玻璃仍随背景取色。

二、先在 Android Studio 模拟器验证

解压后打开 qiping-launcher-v0.2.16。建议 Android 9 / API 28 横屏模拟器。
先 Run app，进入“手机传壁纸”，记录电视画面中地址末尾的端口及配对码。

模拟器的虚拟 IP 通常不能直接从真实手机访问。电脑浏览器可通过 ADB 转发体验：

假设画面显示 http://<DEVICE_IP>:41837/（此地址与端口仅为示例）：

  adb devices
  adb -s <你的模拟器编号> forward tcp:41837 tcp:41837

然后用同一台电脑的浏览器打开：

  http://127.0.0.1:41837/

填写模拟器画面上的配对码，选择电脑图片并上传，再回模拟器按方向键 / Enter 确认。
两侧端口必须都替换为当前显示的真实端口，并保持相同；每次重新连接端口可能变化。
如果同时连接多个设备，-s 后填写 adb devices 列出的对应模拟器编号。
电脑提示 adb 不是命令时，在 Android Studio SDK 目录的 platform-tools 中打开终端；PowerShell 可使用 .\adb.exe。

验证结束后可删除该端口转发：

  adb -s <你的模拟器编号> forward --remove tcp:41837

这条转发只用于电脑上的模拟器验证。电视真机直接按局域网扫码流程操作。

三、建议本轮检查

□ 扫码后打开手机网页，正确显示连接状态；不需要下载安装另一个 App。
□ 用浏览器手动输入地址和配对码，同样可以连接；错误配对码有提示。
□ 影视、直播、音乐、相册、全部应用和设置页面都可以单独设置。
□ 手机选图后有预览；上传后电视显示目标分类和预览。
□ 电视确认前原壁纸不变；确认后目标分类更新，其他分类不变。
□ 遥控器左右可选“结束传输 / 放弃图片 / 应用壁纸”；确定和返回正常。
□ 在同一次连接中，连续上传两张图片并用于不同分类。
□ 放弃图片、无效图片或中途断网后，旧壁纸仍在。
□ 退出页面或打开直播应用后，原上传页面无法继续接收图片。
□ 重新进入生成新二维码；旧页面需要重新扫码或配对。
□ 大号 / 特大字号下内容与按钮可见，没有压到电视安全边距外。

四、打不开页面时

- 确认手机使用 Wi-Fi，且手机和电视位于同一路由器的可互访网络。
- 不要使用开启了设备隔离的访客 Wi-Fi；如果路由器开启了 AP 隔离，也可能无法互访。
- 电视必须停留在传输页面；切出或待机后应重新打开并重新扫码。
- 扫码软件内置浏览器打不开时，复制地址到手机系统浏览器，再输入配对码。
- 请勿改成 https；本功能是家庭局域网 HTTP 传图，请在可信网络使用。
- 当前接收支持私有 IPv4 地址。只有 IPv6、移动数据或 VPN 地址时不会启动局域网接收。
- 图片格式由电视系统解码器判断；手机能预览而电视不支持时，转为 JPG 后再试。
- 手动配对连续错 5 次后，需要在电视结束并重新连接。

五、升级与既有功能

Android 9 及以上；versionName 0.2.16 / versionCode 18。
使用原包名和原签名覆盖安装，保留既有配置；不要为升级先卸载旧版。
本轮不改变首页排列、隐藏、屏保、收藏、应用绑定、备份格式或开机直播状态机。
壁纸图片仍不打包进 .qiping 配置备份。卸载或清除应用数据会删除已保存壁纸，原图请另行保留。
开机直播是否正常进入、海信电视真实待机/唤醒、手机浏览器和家庭路由器互访仍需真机验证。

自动 instrumentation 只用于可清空的测试模拟器，会修改测试绑定和临时壁纸。不要在日常电视上直接运行开发测试。
