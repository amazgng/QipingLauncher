栖屏 0.2.14 重点验收
日期：2026-10-20
设备：目标 Android 电视（个人设备标识已移除）

一、Android Studio
1. 将新工程解压到独立目录，Open 打开含 settings.gradle 的 qiping-launcher-v0.2.14。
2. 先在 Android 9 / API 28、1280×720 横屏模拟器运行；电脑键盘方向键 / Enter / 返回模拟遥控器。
3. 最低系统为 Android 9；compileSdk / targetSdk 35 不要求电视升级至 Android 15。
4. 交付仅源码；保留你的原签名和包名进行覆盖升级，不卸载、不清除原配置。

二、本轮重点
1. 五类主页：逐个左右选择，检查背景、标题同步；蓝灰、紫色、暖金背景下图标内部随之透色，轮廓仍清楚。
2. 快速来回切换：最后选择与背景一致，无黑块、残留旧图、闪退；关闭界面动效时立即切换，不继续渐变。
3. 遥控器：只有当前项出现焦点亮边；上键到设置，下键到应用库；应用库在左右边缘翻页；返回恢复原焦点。
4. 全部应用 / 最近 / 收藏 / 更新 / 应用选择：统一雾谷背景；第三方图标能辨认，应用名称、更新角标清楚。
5. 桌面设置 / 设备 / 开机管理：统一石墨雾景；逐项检查图标、白色焦点和文字，没有亮底导致看不清。
6. 快捷设置 / 字号 / 边距 / 家庭配置 / 恢复预览：背景与所在页面一致，面板文字不透得模糊；确认与返回仍有效。
7. 长辈布局：看电视 / 看照片 / 常用应用图标为透色玻璃；底部“布局与解锁”仍能通过方向键到达。
8. 三档字号、三档边距：图标和文字不裁切；尤其检查 720p、特大字号和 7% 边距。
9. 打开绑定应用再返回、待机唤醒、退出重进：原绑定与设置保留，壁纸和玻璃图标恢复；不循环打开直播。
10. 自动 / 轻量性能模式：使用一段时间观察遥控反应、背景切换和返回恢复。实机流畅度以电视为准。

三、继续待测
电视真正重启后的默认桌面与开机直播仍待实测。本版保留已有启动状态机，待机唤醒不等同于真正重启。
先确认“立即试播”可打开目标应用，再测试冷启动；没打开时查看“启动状态”，保留原始提示以便定位。

四、范围
已安装应用原图案保留并加轻微玻璃高光；电视系统界面和第三方应用内部界面不属于栖屏绘制范围。
在线壁纸与真实更新服务继续暂停。本版没有新增下载或自动安装流程。
