栖屏 0.2.17 · 使用与验收

本版交付 Android Studio 源码；最低 Android 9 / API 28。
请保留已验证的 0.2.16 源码。在新目录解压 0.2.17，使用原包名及你自己的同一签名覆盖安装，无须先卸载。卸载会删除应用内壁纸及设置。

一、手机裁剪壁纸
入口：首页齿轮 → 个性化 → 本地壁纸 → 手机传壁纸。
1. 手机和电视连接同一路由器，扫码打开网页。
2. 选择“用在哪个界面”，再选 JPG、PNG 或 WebP 图片。
3. 预览框为 16:9 电视比例。用一根手指拖动图片调整主体位置，用“缩放”滑块调整大小；左右位置 / 上下位置也可分别调整。
4. 不满意可按“恢复居中构图”。确认预览后，按“上传到电视”。
5. 电视收到的是已裁剪的图片。用遥控器左右选择“应用壁纸”或“放弃图片”，再按确定。
6. 应用后可继续选择下一张；结束时按电视返回键或“结束传输”。

图片限制：单张 20 MB、4800 万像素、最长边 16000 像素；超出时先在手机缩小。输出最多 1920×1080，小图不会凭空增加细节。过度放大会提示可能不够清晰。透明图片以深色底合成，动图及浏览器不支持的格式请先转为 JPG / PNG。原照片不受修改。
裁剪框表示电视构图，不包含电视桌面自动添加的文字区域遮罩。手机横屏预览桌面时，手机屏幕比例可能与 16:9 电视不同。

二、玻璃界面明暗适配
自动生效，无须打开额外开关。
浅色壁纸：增强文字区与顶部时钟遮罩、玻璃卡片底色和图标细描边。
深色壁纸：保留原有通透效果。
背景切换时，明暗适配随切换平滑变化；关闭界面动效时直接切换。
适用于首页、应用列表、设置、弹窗及屏保。没有增加视频壁纸或持续实时模糊。

三、运行诊断
入口 A：设备与性能 → 底部“运行诊断”。
入口 B：开机与桌面 → 启动状态 → “运行诊断”。
1. 查看当前状态：查看版本、运行时间、缓存、内存及开机直播状态。
2. 查看最近记录：上下键滚动；右键到按钮；返回键回到诊断菜单。
3. 导出诊断文件：用系统文件保存界面选择位置，生成 TXT。系统无文件保存界面时会说明，可返回查看并拍照。
4. 清空诊断记录：需要再次确认；返回取消。

日志最多保留 100 条 / 48 KiB，只在本机保存，不自动发送。应用打开事件会包含目标应用包名；不记录图片、原图名字、配对码或二维码地址。每 5 分钟仅在桌面前台采样；离开桌面停止定时采样。
Java 堆、原生堆和缓存数值不是三项独立占用，不能相加；过渡画面可能暂时持有额外图片。数值波动不等于泄漏。诊断不提供“系统加速”或结束其他应用的功能。
突然断电、系统杀进程、原生崩溃或无响应，可能没有记录。启动状态中的“请求已发出”不代表直播已播放。

四、请在你的电视上验证
□ 升级后原绑定、收藏、排列、隐藏、设置和已有壁纸仍在。
□ 选一张竖图：拖动人物到合适位置并缩放，确认电视显示与裁剪框构图一致。
□ 换一张带拍摄方向的照片：预览和电视上都没有旋转错位。
□ 上传非常浅和非常深的两张壁纸：图标仍透出背景色，文字、焦点框都清楚。
□ 首页、全部应用、设置、快捷设置和传图弹窗中，方向键 / 确定 / 返回都正常。
□ 使用大号 / 特大字号、较大边距时，诊断入口和按钮仍可见、可操作。
□ 诊断页面能查看、上下滚动、返回；可用时导出 TXT，取消导出不会改动设置。
□ 反复进出直播、换壁纸和打开弹窗后，桌面响应没有逐渐变慢。
□ 按平常习惯使用数小时或一天，并进行待机 / 唤醒；如有异常，记下发生时间，导出或拍下最近记录。
□ 真正重启后检查开机直播（方便时再做）：是否自动打开、返回桌面后是否再次抢回直播、待机唤醒是否保持预期。

开机直播状态机本版没有调整；此项仍需海信真机验收，不能用模拟器结论替代。

五、Android Studio 模拟器通过电脑浏览器传图
模拟器虚拟网络通常不能由真实手机直接访问。电脑浏览器可以使用 ADB 转发。
1. 在模拟器打开“手机传壁纸”，读取屏幕地址中的端口，例如 41837（仅为示例，每次可能不同）。
2. 在电脑终端运行 adb devices，找到对应的模拟器编号。
3. 运行：adb -s emulator-5554 forward tcp:41837 tcp:41837
   将编号和两处端口替换为你屏幕上实际值；两处端口保持相同。
4. 电脑浏览器访问 http://127.0.0.1:41837/，输入模拟器上的 6 位配对码。
5. 鼠标拖动、滑块调整和上传即可验证。系统文件选图和遥控器确认仍在模拟器中完成。
6. 结束后可移除转发：adb -s emulator-5554 forward --remove tcp:41837
真实电视和手机同网时直接扫码，不需要 ADB。

构建：Android Studio 打开 qiping-launcher-v0.2.17 目录。沿用 JDK 17 / 21、SDK Platform 35、Build Tools 35.0.0、AGP 8.7.3 / Gradle 8.9。测试模拟器建议 API 28、1280×720 横屏。
