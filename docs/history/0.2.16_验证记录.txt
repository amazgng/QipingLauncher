修复及核对范围
- 初次环境启动出现模拟器 System UI 未响应弹窗，关闭阻塞后重测；不是栖屏接收功能报错。
- 原生套接字测试发现拒绝重复上传时，关闭尚有输入的连接会产生 TCP reset，使客户端读不到提示。已先完整发送响应并对剩余输入进行有界处理；加入较大请求体和真实浏览器的错误提示检查，最终通过。
- 手机断连重试限制为连续三次失败，随后停止轮询、禁用上传并提示重新扫码。
- 40 个原 Java 模块字节未变。原模块只有 MainActivity（入口和暂停清理）及 WallpaperStore（内部暂存构造和确认后原子采用）修改；版本号另有更新。壁纸和图标资源保持原样。
- 详细构建、浏览器和设备测试输出见 docs/checks。早期 HTTP 关闭失败输出保留用于追踪；最终输出均已明确分开。

仍需真机验收
- 海信电视与真实手机在家庭路由器下互访，手机自带/扫码内置浏览器，照片格式及真实 Wi-Fi 中断/重新连接。
- 电视真正待机/唤醒、低内存与长期使用。软件渲染模拟器不代表海信电视的耗时或帧率。

- 本环境使用独立 SDK 构建，没有打开 Android Studio GUI 或执行其首次 Gradle 同步。
