# 栖屏电视桌面 0.2.15 · 个性化 / Android 9+

Android Studio 原生工程，Java + 系统 Views，包名 `cn.wengmang.qiping`，versionCode 17，最低 Android 9 / API 28，compileSdk / targetSdk 35。以已验收的 0.2.14 为基础，继续使用半透明玻璃图标、六套内置风景壁纸和遥控器导航。

## 本版五项功能

| 功能 | 入口与行为 |
| --- | --- |
| 应用启动反馈 | 打开应用时显示“正在打开…”，短时间内重复确认只发出一次请求；离开桌面、启动失败或超时后解除。反馈表示已发起请求，不代表应用内部已加载完毕。 |
| 首页排列与隐藏 | 首页齿轮 → 个性化 → 首页排列与隐藏。支持移动、隐藏和恢复默认；剩余图标等间距分布，保持无底栏文字。设置与全部应用入口始终可达。 |
| 全部应用整理 | 全部应用右下角“整理应用”；在应用上长按确定或按菜单键 → 排列与隐藏，可置顶、前后移动、隐藏。固定整理入口可恢复隐藏和默认排序。 |
| 桌面空闲屏保 | 个性化 → 桌面空闲屏保。默认关闭，可选 5 / 10 / 15 / 30 分钟及立即预览。只在首页前台空闲时出现，显示当前壁纸、时钟和日期；按方向键、确定、返回或触摸退出，唤醒操作不会同时打开应用。 |
| 本地壁纸 | 个性化 → 本地壁纸，为影视、直播、音乐、相册、全部应用、设置页面分别选图，也可逐个恢复内置壁纸。自动复制到私有目录，拔掉 U 盘后仍可使用。 |

完整设置页面顶部也有“个性化”。菜单统一使用玻璃风格；方向键选择、确定操作、返回上一级，不增加页码。应用列表原有左右边缘翻页继续有效。

首页自定义只作用于标准布局；长辈布局维持三个大入口。隐藏应用只影响普通“全部应用”列表，不卸载、不删除绑定或收藏，绑定选择器仍能找到它。布局锁定同时保护首页排列和应用排列/隐藏；隐藏状态不是系统级访问限制。

屏保不使用后台服务、不覆盖外部直播/视频应用，不修改系统休眠策略。时钟每分钟刷新并略微移动，复用当前壁纸，不进行持续模糊或视频播放。

壁纸导入最多 20 MB，保存时最长边限制为 1920 像素，处理照片方向；桌面显示继续遵守轻量模式的解码与缓存上限。图片处理在后台线程完成；文件无效、过大、取消或保存失败时保留旧壁纸。使用系统图片选择器，缺失时尝试兼容文件管理器；海信原厂选择器对 U 盘的支持需真机验证。壁纸会随卸载或清除数据删除，原图请自行保留。

## Android Studio 运行

1. 保留 0.2.14 源码作为回退副本。解压新包到独立英文目录，例如 `C:\AndroidProjects\QipingV0215`。
2. Open 打开包含 `settings.gradle` 的 `qiping-launcher-v0.2.15` 文件夹。
3. 使用 JDK 17 或 21；SDK Manager 安装 Platform 35、Build Tools 35.0.0。工程沿用 AGP 8.7.3 / Gradle 8.9，Java 8 源码级别。
4. 首次 Gradle 同步需要下载对应依赖。建议在有硬件加速的 Android 9 / API 28、1280×720 横屏模拟器运行 `app`，用方向键、Enter、返回键操作。
5. 手机横屏也能体验菜单和导入壁纸；电视性能、原厂文件选择器及真正重启行为最终仍需电视验收。

只交付源码、说明和运行截图，不含 APK、签名密钥、SDK 或构建缓存。正式覆盖安装请沿用原来的包名和签名，无须卸载旧版。旧版源码独立保留；Android 对低 versionCode 覆盖安装有限制，保留源码不等于可直接降级安装。

本版最低支持 Android 9 / API 28；Android 8.1 及以下不支持。

## 配置保留与备份

首次升级不清空原四分类绑定、收藏、最近打开、显示与性能设置、长辈布局、锁定和开机配置。

新增 `desktop.home_order`、`home_hidden`、`saver_minutes`，以及 `app_organizer.app_order`、`app_hidden`。缺省使用原五入口顺序、全部显示、屏保关闭；新字段只在明确操作时写入。新增应用接在自定义列表后面，应用扫描失败不会清理已存排序或隐藏记录。应用排列和隐藏各支持最多 128 个已记录包名，总文本分别最多 12,000 字符，超限会提示，不截断旧值。

“全部设置 → 家庭与配置 → 桌面配置”仍提供备份、预览恢复和撤销上次恢复。新导出的 `.qiping` 格式为 v2，包含上述布局与屏保字段，仍有 32 KiB 上限和完整性校验。可导入旧 v1 备份：原有字段正常恢复，新增布局/屏保偏好保持本机状态。旧版 0.2.14 不支持导入新的 v2 文件。

本地壁纸图片不打包进配置备份，恢复配置时保持本机壁纸。备份也不包含外部应用数据、最近记录、旧六槽常用、开机开关或本次启动记录。恢复前有预览；取消不写入；失败回滚与启动时未完成事务恢复保持有效，兼容 0.2.14 的旧恢复记录。

## 现有功能

最近打开、独立收藏、更新角标与现有更新入口、快捷设置、三档字号、三档边距、动效开关、长辈布局、布局锁定、设备信息与自动/轻量性能适配均保留。在线壁纸与真实更新服务接入继续暂停。

本版不修改开机直播状态机。其倒计时、用户操作取消和每次系统重启最多请求一次的策略保留；海信电视真正重启后能否自动进入直播，仍需单独实测。

## 验证与开发

新功能验收步骤见 `0.2.15_验收说明.txt`，实际执行结果见 `验证记录.txt`，运行截图见 `design/runtime/`。

常规构建：Windows 使用 `gradlew.bat :app:assembleDebug`，其他系统使用 `./gradlew :app:assembleDebug`。

独立 SDK 验证：`python3 build_local.py --sdk <SDK路径> --check-api28 --instrumentation`，另需安装 Platform 28。此脚本在本机生成测试包与测试签名，不能用其覆盖你正式签名的应用；这些文件不包含在交付 ZIP 中。

自动交互测试仅限独立测试模拟器：`adb shell am instrument -w cn.wengmang.qiping.tests/cn.wengmang.qiping.tests.LauncherSmoke`。可加 `-e suite personal` 仅运行新功能检查，或 `-e suite regression` 仅运行历史回归。测试会重置测试分类绑定，并使用临时应用列表和图片夹具，不要在保留日常数据的电视上运行 instrumentation。
