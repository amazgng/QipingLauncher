栖屏 0.2.15 · 本轮实际验证记录

构建与环境
- Java 8 源码级别，用官方 Android SDK Platform 28 严格编译全部生产代码与 instrumentation；资源使用 SDK 35 / Build Tools 35.0.0。构建、签名验证与 zipalign 检查通过。
- APK 元数据核对：versionName 0.2.15 / versionCode 17，最低 API 28，targetSdk 35。构建产物仅用于本次测试，交付 ZIP 不含 APK 或测试签名。
- 运行验证在 Android 9 / API 28 x86、1280×720、213 dpi 的软件渲染模拟器完成。此环境不用于推断海信电视的帧率、启动耗时或厂商限制。

已执行结果
- 11 组主机检查通过。PersonalizationTest 有 25,185 个断言，覆盖 120 种首页排列与全部隐藏组合、保留必要入口、写入失败回退、重复启动时间窗、空闲状态、v2 配置往返、v1 恢复和旧恢复日志兼容。原 10 组检查也通过。
- 最终构建分两轮运行 Android 9 检查：既有回归 567 项、新增专项 58 项，共 625 项 PASS，最终两轮无 FAIL。两轮均含一次首页启动检查；使用真实方向键和确认键事件，并结合限定的测试状态注入。
- 首页移动/隐藏及恢复、焦点跳过隐藏项、上下进入设置、重新排列后的右边缘跳转；应用跨页置顶和焦点跟随、全部隐藏空态恢复、绑定选择器仍可选隐藏应用、布局锁定。
- 屏保预览、模拟超时、确认/返回唤醒不误触、焦点恢复；全部应用、设置弹窗、启动倒计时和外部测试应用期间不进入屏保。超时检查通过调整测试中的空闲时间触发，不以此替代电视连续观看测试。
- 启动浮层可见、连续打开请求不会重置启动窗口、外部应用期间清除浮层、回桌面可再次打开。
- 六类本地壁纸保存、最长边限制、EXIF 方向、删除源文件后仍可使用、恢复内置背景；损坏、取消、超过 20 MB 时旧图保留。Activity 选图返回路径通过本地 URI 夹具验证；真实 U 盘选取仍待真机验证。
- 完整回归包括旧布局/玻璃取色、遥控器翻页、更新菜单、收藏与最近、快捷设置、字号/边距、家庭布局与锁定、备份/恢复/撤销/取消、原生配置文件选择器及手动直播测试。
- 已查看新增菜单、首页、应用整理、屏保与壁纸等运行截图。特大字号窗口在安全范围内。

修复与范围
- 前期运行出现收藏菜单焦点等待超时，以及快速开合菜单时移动断言失败。统一补充了全部自动测试按键前对真实窗口焦点的有界等待，保留原焦点/位置断言；桌面同时增加模态窗口过渡保护，仍到达 Activity 的导航键不会触发底下图标。增加模拟该边界的运行检查与失败截图诊断。最终分轮回归通过，前期结果保留在 docs/checks/intermediate_*_failure.txt；电视长期运行仍需实测。
- 启动浮层移除时同步从场景注册表移除玻璃视图，避免反复打开应用积累引用，新增运行断言已覆盖。
- 测试发现并修复屏保退出后系统把焦点回到首项的问题，现保存进入屏保前的焦点，并恢复真实控件焦点。
- 扩展配置数字校验，支持新增 10/15/30 分钟值，同时维持严格范围限制。
- 0.2.14 原 ZIP 的 SHA-256 保持 f46253a22ea566c66a63184deb1e109ca2d1a58c472e979805f20a17b92b5a44。
- 已逐文件核对 14 个既有核心模块与 0.2.14 字节一致，包含开机状态机、绑定、收藏、网格导航和更新策略。详见 docs/checks/source_fingerprints.json。
