# 主页底栏比例 · 0.2.7

## 调整原因

以约 20∶9 的宽屏为例，旧版把 960×540 的设计宽、高分别缩放到屏幕，卡片原本约 2.2∶1，在该屏幕比例下会被拉宽到约 2.7∶1。白色符号也使用同样的拉伸。

## 当前处理

保留整个主页的结构及全宽玻璃底栏，单独修正五个主页入口的绘制。

| 项目 | 当前行为 |
| --- | --- |
| 卡片尺寸 | 142×80 设计单位，约 16∶9 |
| 入口绘制画布 | 168×120 设计单位 |
| 缩放 | 宽度允许比例与高度允许比例取较小值；横、纵始终相同 |
| 居中 | 在当前入口槽位的中心绘制 |
| 选中 | 卡片、圆角和符号一起等比放大 8%；原 180 ms 动画沿用 |
| 白色符号 | 42×42 设计单位，再按自身原有路径绘制 |
| 超宽屏 | 卡片形状不变，多出的宽度转为卡片间距 |
| 玻璃底栏 | 高度 120；底边不动，向上增高 |
| 下方箭头 | 沿用原来的位置和点击行为 |

焦点光晕仍保留，最外侧限制在当前入口的测量区域内。渐变填充前恢复画笔透明度，避免光晕的低透明度影响卡片底色。渐变与矩形复用，避免为此增加每帧分配。

卡片形状保持一致，不代表所有设备上像素尺寸相同。实际大小依然随屏幕和边距缩放；点击区域保留整个入口槽位，便于手机操作。遥控器焦点、上下左右、确定、长按、背景跟随、绑定与返回逻辑未修改。

## 已完成核对

- 960×540、1280×720、1920×1080、2048×921、2400×1080、3840×2160、1024×768，分别搭配三档屏幕边距，进行了静态布局计算。
- 每种组合检查五个放大进度：卡片比例固定、光晕能放入槽位、相邻卡片不重叠、符号不溢出。
- 保留启动提示、音乐封面、底栏与下方箭头的空间关系。
- 标准边距下，1920×1080 的普通卡片计算值为约 284×160 px；2048×921 为约 243×137 px。数字是布局计算结果，不是实机测量。
- 完成 API 14 严格兼容编译和资源编译；既有数据、开机状态与性能策略检查通过。

本轮未运行手机、电视模拟器或海信实机，尚未实测遥控器焦点动画与触摸体验。

## 你可以这样查看

1. 用 Android Studio 打开完整 0.2.7 工程，运行到目前测试的手机上。
2. 看底栏卡片是否比之前更高、更饱满；播放、直播、音乐、相册和四宫格应保持正常比例。
3. 点击不同入口或用方向键切换，观察选中卡片放大时形状是否保持一致。
4. 绑定过的入口照常打开对应应用，返回后应保留原来的选择。
5. 有电视模拟器时，再用 1280×720 或 1920×1080 检查一次。

旧版 0.2.6 源码包已保留，可以独立打开对比。使用相同签名覆盖升级无需清除现有绑定和设置。
