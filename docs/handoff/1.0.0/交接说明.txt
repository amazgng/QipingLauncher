2 已确定的设计与交互

整体参考 Apple TV 的大屏布局：背景随选中分类切换，主页、全部应用、设置与弹窗采用一致的半透明玻璃风格。主页底栏图标不附文字标签，功能名称由主屏展示。内置壁纸与用户本地壁纸均可使用，玻璃明暗会随背景调整。背景不是绑定应用的实时画面。

系统安装图标采用 Q 与电视融合的石墨银白方案，无额外装饰外框。安装图标是静态应用标志；主页内的玻璃图标是另一组界面元素，后续修改时不要混淆。

遥控器为主要操作方式。方向键选择，确定执行，返回上一级；首页下键或最右侧继续右移进入全部应用，应用网格在左右边缘直接翻页。菜单键或长按确定用于普通应用管理。返回时恢复原焦点，弹窗和长说明也需可用遥控器操作，不恢复点击页码的交互。

手机横屏可辅助看界面和测试绑定，但手机长宽比、密度和触摸行为不能代表电视。优先使用 1280×720 横屏模拟器复核，再用电视遥控器验收。

首页排列与隐藏只调整标准布局，长辈布局保留三个大入口。设置与全部应用入口始终可达。布局锁定保护绑定、收藏及相关布局编辑；隐藏应用仅改变列表展示，不能作为未成年访问限制。

3 功能入口与日常使用

标准首页提供影视、直播、音乐、相册四类绑定入口和全部应用。先安装对应的外部应用，再完成绑定。绑定只决定栖屏打开哪个程序，不提供影视内容或直播源。最近打开、独立收藏、应用排列与隐藏均保留。

右上角齿轮打开快捷设置，再进入全部设置。旧的“个性化”分散入口和“第一版常用”入口已经整合，不应在后续版本重新出现。

4 开机与待机唤醒直播

先将栖屏设为默认 HOME 桌面，在“开机与桌面”选择直播应用，用“立即试播”确认绑定目标能够打开。系统重启使用“开机自动打开直播”，遥控器关屏再亮屏通常涉及待机，另使用“待机唤醒也打开直播”。两个开关独立保存。

默认桌面可见、有焦点、目标应用就绪且无弹窗后，显示 3 秒倒计时。用户方向键、确定、返回或触摸可以取消本轮自动打开。每轮最多发出一次请求，系统重启与唤醒不会重复打开。

如果关屏前已经进入外部应用，优先保持原应用；唤醒后栖屏未到前台时不从后台强行切换。唤醒后超过 60 秒才返回桌面，不再补启动。进程被清理且未观测到可靠唤醒时刻时，也不会只凭旧关屏记录猜测启动。

未成年模式的允许列表与时段会同时检查自动打开请求。不符合规则时跳过该轮，不等待未来时段补启动。

排查入口为“开机与桌面 → 启动状态”，必要时再看运行诊断。依次核对默认桌面、直播绑定、两类开关、最近电源记录及是否被用户操作或家长规则取消。“已向系统发送打开请求”只表示请求已发出，不能证明外部软件已经播放。

用户已确认 0.2.19 在该电视开机可进入目标应用，1.0.0 未改动这部分生产代码。升级后仅需确认原行为继续有效，不应将历史未解决的自启动反馈误当成当前状态。

5 未成年模式与数据边界

入口为“全部设置 → 家庭与配置 → 未成年模式”。默认关闭。首次设置需两次输入 6 位密码，保存并确认生成的 12 位恢复码；完成凭据设置后，至少选择一个允许应用才能开启。恢复码由家长自行妥善保管，不写入交接文件。

儿童首页仅显示允许且已安装的应用和家长管理入口，返回键不会退出模式。修改规则或退出需要家长验证。允许时段为每天一个时间窗口，支持跨午夜，开始时刻包含、结束时刻不包含；不是每天累计观看时长。关闭时段限制则全天允许从栖屏打开允许的应用。

模式只限制栖屏发起的应用打开请求，不能停止已在外部软件播放的视频，也不能过滤外部软件内容。系统语音、快捷键、其他桌面、应用内跳转、修改系统时间、卸载或清除数据可能绕过。它不是整机设备管理方案。

密码和恢复码保存在独立 parental_control 私有偏好中，使用随机盐及 PBKDF2-HMAC-SHA256 派生值，不存明文，不进入普通配置备份或诊断记录。密码与恢复码共享错误次数；连续 5 次错误冷却 30 秒。没有通用解锁密码。

退出模式只关闭模式，保留密码、允许列表与时段。覆盖升级应沿用现有规则；普通桌面配置导入和撤销均不能覆盖家长规则。验证授权限定在当前家长操作流程，离开桌面或返回儿童首页后重新验证。

6 壁纸传输与配置备份

手机传壁纸入口为“个性设置 → 本地壁纸 → 手机传壁纸”。手机和电视连接同一路由器，电视可接网线。保持电视传输页打开，手机扫码或在浏览器输入电视显示的 HTTP 地址，并按需要输入 6 位配对码。选分类、选图、完成 16∶9 裁剪后上传，再在电视确认应用或放弃。确认前保留旧壁纸。

传输会话最多 10 分钟；退出、暂停、网络断开或地址变化会停止接收，下次打开换新凭据。支持 JPG、PNG、WebP；原图限 20 MB、4800 万像素、最长边 16000，手机输出最长边 1920 的 JPEG，电视继续校验和缩小。网页随应用打包，无需配套手机 App，也不向云端上传。

传输使用局域网 HTTP，适用于可信家庭网络。访客 Wi-Fi 或 AP 隔离可能阻断访问。Android Studio 模拟器处于虚拟网络，电脑可用 adb forward 将其传图端口转发到本机浏览器测试，命令见快速运行说明；不能直接把模拟器内网地址当作手机可达地址。

六个页面分类都可使用本地壁纸，也可逐个恢复内置壁纸。导入图片会复制到应用私有目录，拔掉 U 盘仍可使用；卸载或清除应用数据会删除这些副本，原图应另行保存。

桌面配置入口为“家庭与配置 → 桌面配置”。导出为 .qiping v2，最大 32 KiB，带完整性校验。恢复先预览、再确认；支持撤销上次恢复，失败回滚与未完成事务恢复。备份内容校验用于发现损坏，不是文件加密。

备份范围 | 内容
包含 | 四分类绑定、收藏顺序、字号、边距、动效、性能档、长辈布局、布局锁定、首页及应用排列与隐藏、屏保等待时间
不包含 | 壁纸图片、外部应用数据、最近记录、旧六槽常用、开机与唤醒开关和运行状态、未成年规则、密码及恢复码
旧版兼容 | 可读 v1 备份，旧备份不含的新布局和屏保偏好保持本机状态；0.2.14 不支持导入 v2

导出仅接受有效 content:// 提供方返回的位置。系统没有保存界面时，可使用应用固定备份目录的回退路径。不要为了兼容某个文件管理器而重新放开外部 file:// 写入。配置恢复不会立即打开直播；若本机开机开关已开，下次启动使用恢复后的直播绑定。

7 Android Studio 构建与覆盖升级

第一步，解压交接包，再解压其中的源码 ZIP 到独立英文目录。Android Studio 的 Open 应选择包含 settings.gradle 的 qiping-launcher-v1.0.0 文件夹，不是上层交接包目录。保留未经改动的源码 ZIP。

第二步，设置 Gradle JDK 为 17 或 21，在 SDK Manager 安装 Android SDK Platform 35 和 Build Tools 35.0.0。工程固定使用 AGP 8.7.3 / Gradle 8.9，不要因同步提示随意升级全套工具。首次同步需要下载依赖，网络错误与应用代码错误应分别处理。

第三步，建立有硬件加速的 Android 9 / API 28 横屏模拟器，建议绘制区 1280×720，运行 app。方向键、Enter、返回键测试遥控流程；需要自动启动专项时，在该独立模拟器内先设为默认 HOME。

第四步，完成设置菜单和家庭功能的补充回归，再准备电视升级。使用电视现有安装所对应的原签名和相同包名，versionCode 22 高于 0.2.19 的 21。签名密钥、别名及密码由用户在本机管理，无须发送给接手者。

日常覆盖升级不需要先卸载。若系统提示签名不一致，先核对现有签名与构建方式，不要以卸载作为第一处理步骤；卸载或清除数据会丢失私有设置、壁纸与家长规则。普通配置备份无法替代这些数据的完整保留。

Android Studio 的调试签名、build_local.py 生成的本机测试签名，以及用户实际安装签名可能不同。build_local.py 只用于隔离验证，不应用其测试密钥发布正式更新。

回退源码不等于能直接降级安装 APK。需要回到旧逻辑时，应先保留数据并评估版本序号和原签名，不能假定低 versionCode 可覆盖。后续维护版本应递增 versionCode，并同步 app/build.gradle、Manifest 与独立构建输出文件名。

9 正式版三处修补与维护约束

密码冷却：首次跨重启验证时，将估算的剩余等待限制为最多 30 秒，持久绑定到本次启动的单调时钟。页面重开、进程重建或系统时间继续回拨不再无限延长本次等待。仍有效的冷却不会因为再重启就直接清除。迁移写入失败或记录异常时不授权，应提示错误。

导出地址：MainActivity 的配置导出结果只接收分层且有提供方的 content:// URI。在打开输出流之前拒绝外部 file://、https://、无 authority 或不分层的 content:，防止文件选择器借桌面权限覆盖其他文件。受信任的应用内备份读取与固定目录导出保留。

损坏时段：已开启时间限制后，字段类型错误、越界或缺失一端时停止放行。家长验证后重新输入开始和结束时间，两步完整完成才保存；相同起止时间拒绝，中途取消继续保留限制。只有两个字段都未保存时，才兼容旧版默认 19:00 至 20:00。

相对 0.2.19，生产改动限于 MainActivity.java、ParentalStore.java，以及 Manifest 与 app/build.gradle 的版本字段；另更新独立构建脚本、测试与说明。原有开机唤醒、其余 Java 业务、资源和网页素材的逐文件一致性记录已随源码保存。

后续不要把损坏规则视为“无限制”，不要让普通配置导入覆盖家长凭据，不要放开外部直接文件导出路径，也不要在后台强行拉起直播。保持取消、存储失败和生命周期离开时的授权与状态检查。

优先在有硬件加速的独立模拟器检查：个性设置全部入口往返、家庭与配置、家长密码录入、允许列表、正常时段修改、开启与退出模式、返回焦点。随后在电视原签名覆盖升级，确认版本号、绑定、收藏、壁纸、家长规则保留，再检查日常遥控关开与配置导出预览。

自动交互专项会修改测试设置、清理测试实例的家长规则并启动测试应用，只能在可丢弃的模拟器运行。不要在日常电视执行自动清理型测试，也不必故意损坏电视数据或改系统日期来复现边界。待验收清单另附，实际结果留空，供完成后填写。

11 性能与常见问题排查

低内存电视适合轻量模式。自动策略在低内存设备、总 RAM 不超过 1.5 GiB、应用堆不超过 128 MiB 或读数缺失等条件下使用轻量档。设备页面显示当前设备真实读数；桌面绘制区不等于电视面板物理分辨率。

轻量档背景最大边 960、背景缓存最多 2 张且受 4 MiB 预算约束；标准档最大边 1920、最多 3 张且受 20 MiB 约束。这些预算不是整个进程的总内存，前后过渡帧与解码也占用内存。保持按需加载和生命周期释放，不加入持续逐帧模糊或后台视频壁纸。

传图页面打不开：核对同一家庭网络、电视会话未结束、地址未变化，再检查访客网络隔离和浏览器限制。手机已上传但壁纸没变时，先检查电视是否还等待确认。

备份导出失败：先看可用存储与系统文件选择器，使用系统提供的位置或固定备份目录回退。不要改为接受任意文件路径。恢复只需先预览即可检查备份可读，不必为验收直接覆盖当前设置。

家长密码失败：区分密码错误、30 秒冷却与存储异常。忘记密码使用已保存恢复码，丢失时不能假装存在后门口令。应用数据清除会丢失规则和其他私有数据，不作为普通修复建议。

界面裁切或图标比例异常：核对横屏分辨率和屏幕边距，回到三档字号与三档边距的组合检查；不要按手机超宽屏截图直接重写电视布局。

运行诊断位于“设备与性能 → 运行诊断”，也可从启动状态进入。最多 100 条 / 48 KiB，保存在应用私有目录，不自动上传；包括生命周期、内存快照、启动与传图状态。它不含外部应用日志，断电、原生崩溃或系统杀进程也可能没有完整记录。
