栖屏 0.2.12｜第三轮：快捷设置

实施范围
1. 首页右上角原齿轮打开安全区内的右侧快捷设置；共六行：字号大小、屏幕边距、界面动效、设备与性能、系统设置、全部设置。
2. 沿用原场景、GlassPanel/GlassButton 与 Symbols 符号；不新增实时截图模糊、在线主题或新的界面框架。
3. 字号页提供标准 / 大号 / 特大，方向键只移动焦点；明确按确定并保存成功后更新字体、选中勾与文字预览。仅影响栖屏内部文字。
4. 边距仍为 3% / 5% / 7%，与完整设置共用原字段；界面动效由原「背景动效」改名，继续影响背景过渡与焦点动画。
5. 打开侧栏保留来源焦点；上下移动限制在当前面板，左右不穿透；子页返回恢复父行，关闭返回齿轮。新面板收到没有配对按下的确定键重复/释放时不激活首项。
6. 从设备页返回其侧栏行；从全部设置进入开机、设备、更新等子页后，按原层级退回完整设置，再退回侧栏「全部设置」。配置变化和状态 Bundle 保留侧栏页与焦点。
7. 完整设置的全部九项能力，以及启动状态、使用说明、原更新入口仍可达。系统设置使用真实 Android Intent 跳转，外观由原厂固件决定；Home / 音量不在新面板的自定义按键分支中。
8. 特大文字复用现有全局布局单位，只有文字加大；设置及设备卡片补足必要行高，标准 / 大号保留原布局尺寸。

偏好兼容
- SharedPreferences 文件仍为 desktop，原绑定、旧六槽常用、收藏和最近记录不迁移、不清空。
- 新 font_size：整数 0=标准、1=大号、2=特大；只有用户明确选字号才写入。
- 读取优先使用有效 font_size。没有此键、值越界或类型损坏时，回退原 large_text：false=标准、true=大号。读取不进行隐式写入。
- 写入字号时同时写 font_size 和 large_text；0 对应 false，1/2 对应 true。旧版本只能显示原两档，会把特大当大字；新版本已有有效 font_size 时优先该值。
- 标准 / 大号像素字号与原来相同；特大在原大字号基础上增加 10%，不改变电视系统字体设置。
- margin（0 / 1 / 2）和 reduce_motion（关闭动效时 true）继续使用原字段与语义；完整设置与快捷设置读取同一份值。
- 侧栏写入使用 commit 结果；失败时恢复受影响的内存值、提示失败，不提前改变勾选或预览；不改动同一偏好文件的其他字段。
- 未新增启动 token、开机执行状态、后台服务、网络轮询、系统权限或第三方依赖。
