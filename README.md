## 1.0.0 正式版维护修复

1. 修复密码冷却在重启、系统时间回拨后可能等待异常延长的问题。首次跨重启验证时，把剩余等待转换为本次启动的单调时钟，并持久保存；最多等待 30 秒。冷却期间重开页面或进程不会重新计时，恢复码与密码共用限制。存储失败不授予访问，并提示检查存储。
2. 配置导出只接受有有效提供方的 `content://` 位置，拒绝外部文件选择器返回的 `file://` 等地址，防止以桌面权限覆盖其他文件。系统缺少文件选择器时，仍可导出到本应用固定备份目录；应用内备份仍可预览恢复。
3. 未成年模式启用时段限制后，时间字段类型错误、超界或缺失一端均停止放行，并提示家长修复。输入新的开始和结束时间后一起保存，中途取消保留限制。旧版未单独修改起止时间的 19:00—20:00 默认规则继续兼容；普通配置备份仍不覆盖家长密码与规则。

本版从最后确认的 0.2.19 工程修补，界面与已确认的功能沿用。版本号为 `1.0.0`，内部升级序号 `22`；可用原签名覆盖 0.2.19（序号 21）。实际检查结果见 `验证记录.txt`。本轮构建、16 组主机检查及 Android 9 修补专项通过；完整设置/家庭 UI 回归受模拟器系统中断与重试超时影响，未计为通过，请先在电脑模拟器复核菜单往返。

## 设置入口与未成年模式

- 首页齿轮 → 全部设置 → **个性设置**：界面动效、屏幕边距、显示字号、首页排列与隐藏、全部应用整理、桌面空闲屏保、本地壁纸。
- **家庭与配置**：长辈布局、布局锁定、未成年模式、桌面配置。
- 未成年模式默认关闭，先设置 6 位密码、保存并确认 12 位恢复码，再选择允许应用和可用时段。退出与修改规则需家长验证。
- 密码与恢复码使用加盐派生值保存，不写入日志或普通配置备份；覆盖升级沿用原凭据。输入页使用遥控器数字键盘。

这是桌面内的应用入口限制，不能强制停止外部视频或过滤应用内内容。系统快捷键、语音助手、其他桌面、修改系统时间或清除应用数据等不在桌面控制范围内。

使用与验收步骤见 `1.0.0_使用与验收.txt`。

## 保留的待机唤醒直播

“全部设置 → 开机与桌面 → 待机唤醒也打开直播”仍为独立开关。真实系统重启与待机唤醒分别处理；HOME 可见且就绪后倒计时 3 秒，用户操作可取消，每轮最多发出一次请求。关屏前已进入外部应用时优先保持原应用。0.2.19 的开机进入绑定应用已由用户确认可用；本版未改动开机和唤醒状态机。

## 保留的 0.2.17 功能

- 手机端 16:9 裁剪：单指拖动、缩放、左右 / 上下位置、恢复居中，预览与上传使用相同构图；先在手机生成最长边 1920 的 JPEG，再由电视确认应用。原照片不变。
- 玻璃界面随壁纸明暗适配：图片加载时提取小样本，调整卡片、图标描边、文字 / 顶部时钟背景和屏保遮罩。深色图片保留原有通透度，浅色图片增强对比度；切换时随背景渐变。
- 运行诊断：设备与性能 → 运行诊断；开机与桌面 → 启动状态也可进入。显示运行状态、最多 100 条 / 48 KiB 记录，支持系统文件导出与确认清空。
- 连续运行检查及资源管理：合并重复应用扫描；发布到 ImageView 的预览图片解除引用后交由系统释放；前台每 5 分钟轻量采样，离开桌面暂停，无新增后台常驻服务。

具体使用与电视验收见 `1.0.0_使用与验收.txt`，实际测试范围见 `验证记录.txt`。

## 手机传壁纸

入口：**首页齿轮 → 全部设置 → 个性设置 → 本地壁纸 → 手机传壁纸**。各分类的壁纸菜单中也有同名入口。

1. 手机与电视连接同一路由器；电视可以通过网线连接。电视停留在传输页面。
2. 手机扫码打开浏览器页面。扫码软件打不开时，用浏览器输入电视上的 `http://地址:端口/`，再填 6 位配对码。
3. 手机选择目标分类和一张图片，拖动图片或调整缩放、位置，确认 16:9 构图后上传。
4. 电视显示图片预览。按左右键选择 **应用壁纸** 或 **放弃图片**，按确定执行。
5. 可继续为其他分类上传；结束时在电视按返回或选择 **结束传输**。

连接最多持续 10 分钟。退出页面、进入其他应用、系统暂停桌面、网络断开或地址改变时停止接收；重新打开会生成新二维码和配对码。未确认的图片不会替换原壁纸。手机选图支持 JPG / PNG / WebP，单张最多 20 MB、4800 万像素、最长边 16000；浏览器需能正确读取方向。手机生成裁剪后的 JPEG，电视继续检查、缩小和保存，保留玻璃透色效果。透明区域以深色底合成。

网页、样式和脚本全部随源码打包，手机无须安装配套 App；图片经局域网直接传到电视，不使用云端上传。传输使用局域网 HTTP，请在可信家庭网络使用。仅支持 Wi-Fi / 有线网络的私有 IPv4 地址；访客网络或 AP 隔离可能阻止手机访问电视。

Android Studio 模拟器位于虚拟网络中，手机通常不能直接访问其屏幕上的地址。电脑可运行 `adb forward tcp:8765 tcp:<传图页面显示的端口>`，再用浏览器访问 `http://127.0.0.1:8765/` 并输入页面配对码测试。

## 保留的界面自定义功能

| 功能 | 入口与行为 |
| --- | --- |
| 应用启动反馈 | 打开应用时显示“正在打开…”，短时间内重复确认只发出一次请求；离开桌面、启动失败或超时后解除。反馈表示已发起请求，不代表应用内部已加载完毕。 |
| 首页排列与隐藏 | 首页齿轮 → 全部设置 → 个性设置 → 首页排列与隐藏。支持移动、隐藏和恢复默认；剩余图标等间距分布，保持无底栏文字。设置与全部应用入口始终可达。 |
| 全部应用整理 | 全部应用右下角“整理应用”；在应用上长按确定或按菜单键 → 排列与隐藏，可置顶、前后移动、隐藏。固定整理入口可恢复隐藏和默认排序。 |
| 桌面空闲屏保 | 个性设置 → 桌面空闲屏保。默认关闭，可选 5 / 10 / 15 / 30 分钟及立即预览。只在首页前台空闲时出现，显示当前壁纸、时钟和日期；按方向键、确定、返回或触摸退出，唤醒操作不会同时打开应用。 |
| 本地壁纸 | 个性设置 → 本地壁纸，为影视、直播、音乐、相册、全部应用、设置页面分别选图，也可逐个恢复内置壁纸。自动复制到私有目录，拔掉 U 盘后仍可使用。 |

“个性设置”仅保留在全部设置的大卡片中。菜单统一使用玻璃风格；方向键选择、确定操作、返回上一级，不增加页码。应用列表原有左右边缘翻页继续有效。

首页自定义只作用于标准布局；长辈布局维持三个大入口。隐藏应用只影响普通“全部应用”列表，不卸载、不删除绑定或收藏，绑定选择器仍能找到它。布局锁定同时保护首页排列和应用排列/隐藏；隐藏状态不是系统级访问限制。

屏保不使用后台服务、不覆盖外部直播/视频应用，不修改系统休眠策略。时钟每分钟刷新并略微移动，复用当前壁纸，不进行持续模糊或视频播放。

壁纸导入最多 20 MB，保存时最长边限制为 1920 像素，处理照片方向；桌面显示继续遵守轻量模式的解码与缓存上限。图片处理在后台线程完成；文件无效、过大、取消或保存失败时保留旧壁纸。使用系统图片选择器，缺失时尝试兼容文件管理器；海信原厂选择器对 U 盘的支持需真机验证。壁纸会随卸载或清除数据删除，原图请自行保留。

## Android Studio 运行

1. 保留 0.2.19 源码作为回退副本。解压新包到独立英文目录，例如 `C:\AndroidProjects\QipingV100`。
2. Open 打开本仓库根目录（包含 `settings.gradle`）；若使用原交接包，则打开其中的 `qiping-launcher-v1.0.0` 文件夹。
3. 使用 JDK 17 或 21；SDK Manager 安装 Platform 35、Build Tools 35.0.0。工程沿用 AGP 8.7.3 / Gradle 8.9，Java 8 源码级别。
4. 首次 Gradle 同步需要下载对应依赖。建议在有硬件加速的 Android 9 / API 28、1280×720 横屏模拟器运行 `app`，用方向键、Enter、返回键操作。
5. 手机横屏也能体验菜单和导入壁纸；电视性能、原厂文件选择器及真正重启行为最终仍需电视验收。

交付源码、说明和历史设计参考，不含 APK、签名密钥、SDK 或构建缓存。正式覆盖安装请沿用原来的包名和签名，无须卸载旧版。旧版源码独立保留；Android 对低 versionCode 覆盖安装有限制，保留源码不等于可直接降级安装。

本版最低支持 Android 9 / API 28；Android 8.1 及以下不支持。

0.2.15 加入的 `desktop.home_order`、`home_hidden`、`saver_minutes`，以及 `app_organizer.app_order`、`app_hidden`。缺省使用原五入口顺序、全部显示、屏保关闭；新字段只在明确操作时写入。新增应用接在自定义列表后面，应用扫描失败不会清理已存排序或隐藏记录。应用排列和隐藏各支持最多 128 个已记录包名，总文本分别最多 12,000 字符，超限会提示，不截断旧值。

## 现有功能

最近打开、独立收藏、更新角标与现有更新入口、快捷设置、三档字号、三档边距、动效开关、长辈布局、布局锁定、设备信息与自动/轻量性能适配均保留。在线壁纸与真实更新服务接入继续暂停。

系统重启状态机保留；另增加独立的待机唤醒流程。两种触发不会重复发送启动请求。唤醒后如果电视仍停留在别的应用，栖屏不会从后台切换；超过 60 秒后返回桌面不再补启动。各电视系统的待机 / 唤醒信号可能不同，其他机型应自行验证。

## 诊断记录的范围

记录保存在应用私有目录，不自动上传。包含栖屏生命周期、内存采样、应用打开请求的包名、开机直播状态、传图状态及尽力保存的未处理 Java 异常类型 / 栖屏代码位置；不记录图片内容、原图文件名、二维码地址或配对码。外部应用日志不在记录范围内。

Java 堆、原生堆及图片缓存读数有重叠，不能相加作为进程总内存；过渡绘制帧不计入缓存读数。突然断电、系统杀进程、原生崩溃或无响应可能无法留下记录。系统未提供文件保存界面时，可在电视上查看并拍下记录。导出只通过用户选择的系统文件位置完成。
